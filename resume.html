  2. ProjectNov 2025 – Now

    Homelab

    My own servers, run out of my apartment

    What I built

    A Proxmox server running my own services in containers, from Pi-hole to my own cloud storage. Each one is exposed through a Cloudflare Tunnel, and Tailscale lets me reach everything remotely and privately. It's paused for now, but it's never really done.

    What it taught me

    Networking, first and foremost. Routing each container through Proxmox, exposing it through a Cloudflare Tunnel, and setting up Tailscale teaches you a ton.

    It also taught me to define scope. At the start I wanted everything, and I wanted it perfect the first time, so I sank hours into one piece before moving on. Now I work v1 first: cut the scope to the core, build v1, pick the next set of features, and repeat.

    Skills

    • Proxmox
    • Linux
    • Networking
    • Cloudflare Tunnel
    • Tailscale
